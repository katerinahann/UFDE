# Public institutional documents

Approved for public derivatives by UFDE on 20 September 2026. Only the four redacted PDFs under `apps/web/public/documents` may be published. Private source files are not included in this repository.

The derivatives retain the supplied source text, with permanent redactions of signatures, residential addresses and internal membership information. Each has an explanatory cover and a public-copy label. They are not certified copies. The statutes cover explicitly notes the difference between article 12 and section 4.2 of the 9 March 2026 minutes; no statutory wording was rewritten.

Static/demo rendering uses the approved document configuration. CMS installations must apply migration `202609200014_public_governance_documents` and rebuild the frontend. Partnership data similarly uses migration `202609200013_approved_partners`. These migrations were tested locally; application to a production database is not verified.
